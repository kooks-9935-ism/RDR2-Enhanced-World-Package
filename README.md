## Häufig gestellte Fragen (FAQ)

**Ist dieses Paket mit Online-Modi (Red Dead Online) kompatibel?
**Die grafiknahen Mods wirken nur im Einzelspielermodus. Einige Gameplay-Tweaks könnten in Online-Umgebungen zu Problemen führen. Wir empfehlen, für Online-Spiele die Mods zu deaktivieren, um Account-Sperren zu vermeiden.

**Mein Spiel stürzt nach der Installation ab. Was kann ich tun?
**Stellen Sie sicher, dass Sie die neuesten Grafiktreiber (NVIDIA Game Ready oder AMD Adrenalin) installiert haben. Versuchen Sie, die Einstellungen der Mods über die beigefügte Konfigurationsdatei (`settings.xml`) zu reduzieren. Eine Neuinstallation des Spiels und des Mod-Pakets kann ebenfalls helfen.

**Unterstützt dieses Paket Mods wie ScripthookV oder Lenny's Simple Trainer?
**Ja, unser Paket ist kompatibel mit gängigen Frameworks wie ScriptHookV. Es kann jedoch zu Konflikten kommen, wenn Sie mehrere komplexe Mods gleichzeitig verwenden. Testen Sie daher einzelne Mods schrittweise.

**Wo finde ich Einstellungen, um einzelne Features zu deaktivieren?
**Nach der Installation finden Sie eine Konfigurationsdatei namens `RDR2_EnhancedWorld.ini` im Hauptspielverzeichnis. Dort können Sie mit einem einfachen Texteditor (wie Notepad) jeden Mod einzeln aktivieren oder deaktivieren.
